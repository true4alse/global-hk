- step-*.webp: 이용 단계 7개 사진. 원본 이미지 채우기의 크롭 좌표를 반영했습니다.

원본의 REZUIRED 오기는 REQUIRED로 정정했습니다. 예약 테두리 문구는 시안의 안내 배지이며 예약 제출 기능은 아닙니다.
