# 로컬 Noto Sans

2026-10-05에 공식 https://github.com/google/fonts 저장소의 main/ofl 경로에서 받은 가변 TrueType 폰트입니다. 파일 이름만 간단히 바꾸었으며 폰트 내용은 수정하지 않았습니다.

| 파일 | 원본 경로 |
| --- | --- |
| NotoSans.ttf | notosans/NotoSans[wdth,wght].ttf |
| NotoSansArabic.ttf | notosansarabic/NotoSansArabic[wdth,wght].ttf |
| NotoSansDevanagari.ttf | notosansdevanagari/NotoSansDevanagari[wdth,wght].ttf |
| NotoSansJP.ttf | notosansjp/NotoSansJP[wght].ttf |
| NotoSansSC.ttf | notosanssc/NotoSansSC[wght].ttf |

각 서체의 SIL Open Font License는 같은 폴더의 *-OFL.txt에 보관합니다.
css/language-fonts.css에서 상대 경로로 연결하며, 페이지는 외부 폰트 서버에 요청하지 않습니다. 배포할 때 이 폴더도 함께 업로드해야 합니다.
