# 솔라피 문자 알림 운영

기본값은 disabled이며 실제 문자 발송은 실행하지 않았습니다. 기존 번호 설정을 유지합니다.

## 준비
1. scripts/migrate.php 실행으로 sms_jobs를 생성합니다.
2. config/sms.example.php를 웹 루트 밖의 비공개 위치에 복사합니다. 키/시크릿/인증된 발신번호를 입력합니다. config/sms.local.php에는 비공개 파일을 require하는 연결만 둡니다. Git에는 포함하지 않습니다.
3. mode: disabled는 대기열도 만들지 않습니다. simulate는 새 예약을 모의 처리하고 네트워크를 사용하지 않습니다. live는 실제 유료 발송입니다. 키 설정만으로 live로 바꾸지 마세요.
4. admin_url은 로컬 테스트에서 비워둡니다. 배포 후 공개 HTTPS 관리자 주소를 설정합니다. 환자 이름·연락처·증상은 문자에 넣지 않습니다. 90바이트를 넘으면 LMS로 발송합니다.
5. Windows 작업 스케줄러 또는 호스팅의 cron에서 PHP CLI scripts/send_sms.php를 1분 간격으로 실행해야 합니다. 예약 API는 외부 서비스를 호출하지 않습니다. Cafe24 상품의 주기 실행/PHP CLI 지원을 배포 전 확인해야 합니다.

## 동작과 실패
- 예약이 저장된 후 활성·수신 설정된 번호만 대기열에 기록합니다. 같은 예약/번호는 중복 등록하지 않습니다.
- 꺼져 있던 기간의 예약을 소급 발송하지 않습니다. 모의 대기열은 live에서 발송하지 않습니다.
- 발송 전 현재 수신 설정을 재확인합니다. 해제/삭제/번호 변경된 수신자 및 24시간이 지난 대기는 취소합니다.
- 단일 DB 잠금으로 작업 동시 실행을 방지합니다. HTTP 429는 5분 간격 최대 3회 시도합니다. 오류/통신 단절/작업 중단으로 접수 여부가 불명확하면 unknown으로 남기며 자동 재발송하지 않습니다.
- accepted는 솔라피 접수 완료이며 단말 수신 성공이 아닙니다. 최종 결과는 솔라피 콘솔에서 확인합니다. 최종 수신 결과 자동 동기화는 별도 후속 작업입니다.
- 계정 관리의 문자 알림 기록에서 최근 100건을 확인합니다. 번호는 마스킹합니다. 비밀키와 업체 응답 원문은 로그에 남기지 않습니다.
- 대기열 DB 오류가 나도 예약은 성공 처리하며 PHP 오류 로그에 HK SMS queue failed가 기록됩니다. 해당 예약은 자동 복구하지 않으므로 이 로그 발생 시 최근 예약을 확인해야 합니다.
- 실발송 테스트는 업체 계정 준비 후 지정된 테스트 번호로만 진행합니다. 기존 담당자 번호로 테스트 문자를 무단 발송하지 않습니다.
