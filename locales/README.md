# 번역 파일 안내

각 파일은 한국어 원문으로 시작하는 독립된 번역 작업 파일입니다. 해당 파일의 문구를 번역하고 저장하면 그 언어를 선택한 화면에 반영됩니다. ko.js를 나중에 수정해도 다른 언어 파일을 자동으로 덮어쓰지 않습니다.

| 메뉴 | 언어 | 수정할 파일 | 언어 코드 |
| --- | --- | --- | --- |
| KOR | 한국어 | ko.js | ko |
| ENG | 영어 | en.js | en |
| CHN | 중국어 | zh.js | zh |
| JPN | 일본어 | jp.js | ja |
| RUS | 러시아어 | ru.js | ru |
| MON | 몽골어 | mn.js | mn |
| HIN | 힌디어 | hi.js | hi |
| ARA | 아랍어 | ar.js | ar |
| VIE | 베트남어 | vi.js | vi |

- 위에서 아래로 섹션 제목을 따라 번역하세요. 키 이름과 배열 순서는 유지하고, 값에 있는 문구만 바꿉니다.
- 이미지 설명(Alt), 버튼, 접근성 이름, 페이지 제목도 번역 대상입니다.
- 예외: 둘러보기 사진의 대체 설명과 사진 선택 라벨은 번역하지 않습니다. 이 문구는 index.html에서만 관리하며, 언어 파일에는 사진별 photos 항목을 두지 않습니다. 층별 설명과 제목은 계속 번역합니다.
- `\n`은 의도한 줄바꿈입니다. 문구에 큰따옴표를 넣으려면 `\"`로 적습니다.
- 파일 하단의 `export default` 연결 부분은 수정하지 않습니다.
- 외국어 번역 시 index.html은 수정하지 않습니다. 한국어 기본 문구를 변경할 때만 ko.js와 index.html을 함께 수정합니다.
- 일본어 파일명은 jp.js이며, 웹 표준 언어 코드와 주소에는 ja를 사용합니다.
- 아랍어를 선택하면 문서 방향은 오른쪽에서 왼쪽(RTL)으로 전환됩니다. 실제 번역 완료 후 긴 문구와 배치는 별도 확인이 필요합니다.
- 번역 전에는 언어를 변경해도 문구가 한국어로 보이는 것이 정상입니다. 현재 선택, 주소, 불러오는 파일은 변경됩니다.
- 로컬 주소는 `/en/`, `/ja/` 방식이며 GitHub Pages에서는 `?lang=en`, `?lang=ja` 방식입니다. 새로고침 시 선택한 언어를 유지합니다.
- 언어 선택은 site_language 쿠키에 1년간 저장합니다. 언어가 없는 기본 주소로 재방문할 때 사용하며, 주소에 명시된 언어가 있으면 주소를 우선합니다.
- 한국어·영어는 기존 글꼴을 유지합니다. 나머지는 assets/fonts/noto에 저장된 Noto Sans 계열(SC/JP/Arabic/Devanagari 포함)을 사용합니다. 외부 Google Fonts 연결은 필요하지 않습니다. 한국어로 남아 있는 임시 문구는 기존 한글 글꼴로 보일 수 있습니다.
- 디자인 고유 서체 예외: 메인 수치, HSS 영문 타이틀과 평가 연수, APKASS/ICKAS/FOUNDER, SPECIALTY CENTER는 언어와 관계없이 기존 Playfair 세리프를 유지합니다.
