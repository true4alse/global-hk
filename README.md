## 실행

이 폴더에서 `node server.cjs`를 실행하고 http://127.0.0.1:4173/ko/ 를 엽니다. index.html을 직접 더블클릭하는 방식이 아닌 로컬 서버를 사용합니다.

## 무엇을 왜 나눴는가

- index.html: 공통 헤더의 의미 있는 HTML. 다음 단계에서 main 안에 첫 섹션을 추가합니다.
- css/header.css: 시안의 60px 상단 + 33px 메뉴, 원본 로고, 색상과 간격. 760px 이하에는 로고를 첫 줄로, 메뉴를 3열 2줄로 배치하여 겹침을 방지했습니다. 모바일 배치는 이번 구현의 보완안입니다.
- locales/ko.js: 한국어 기준 문구. 시안에 있는 영어 메뉴는 임의 번역하지 않았습니다.
- js/i18n.js: 공통 화면 + 언어별 데이터라는 이전 합의 유지. 언어 URL 우선, 쿠키 보조, lang/dir 및 lang-* 클래스, 현재 경로·쿼리·해시를 보존하는 언어 URL 함수입니다. 번역 데이터가 없는 언어는 선택 불가이며 한국어로 처리합니다. 아랍어 데이터가 연결되면 rtl이 적용됩니다.
- js/header.js: 언어 선택 열기/닫기, Escape와 바깥 클릭·포커스 이동 처리. 전체 HTML 재생성 없이 문구만 연결하여 이벤트를 유지합니다. 후속 섹션에 언어별 마크업이 필요하면 해당 콘텐츠 단위 모듈을 추가합니다.
- assets/: Figma가 제공한 원본 4개를 저장하여 임시 URL 만료 후에도 유지됩니다.

## 현재 범위와 확인할 내용

- global 클릭과 키보드 조작 가능. 한국어 외 번역은 아직 없습니다.
- 6개 메뉴의 이동 대상은 다음 섹션 구현 후 연결합니다. 현재 aria-disabled 상태입니다.
- +82-10-1111-2222는 시안 번호라 통화 연결하지 않았습니다.
- Pretendard는 설치되어 있으면 사용하며 없으면 맑은 고딕/sans-serif를 사용합니다. 정식 폰트 파일 연결 전에는 글자 폭이 다를 수 있습니다.
- 지구본은 원본 모션의 2초 선형 반복 회전을 적용했습니다. 동작 줄이기 설정에서는 정지합니다.
- 운영 PHP/DB, 번역, 예약 기능과 다른 본문 섹션은 이번 단계 범위 밖입니다. 현재 로컬 서버는 홈 언어 경로만 제공합니다.
